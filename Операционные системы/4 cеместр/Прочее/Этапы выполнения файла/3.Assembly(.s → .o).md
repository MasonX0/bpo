### **Ассемблирование**

```
gcc -c example.s -o example.o
# или напрямую из .c
gcc -c example.c -o example.o
```

**Что происходит:**

- Преобразование мнемоник ассемблера в машинный код
    
- Создание relocatable объектного файла
    
- Заполнение таблицы символов

**Программа:** `as` (ассемблер GNU)
