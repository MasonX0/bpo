### **Линковка**

```
gcc example.o -o example

```

**Что происходит:**

1. **Разрешение символов** - поиск `printf` в библиотеках
    
2. **Распределение памяти** - расстановка по виртуальным адресам
    
3. **Релокация** - исправление адресов
    
4. **Создание ELF** - формирование заголовков и секций

**Программа:** `ld` + `collect2`


```
# Динамическая (по умолчанию)
gcc example.o -o example_dynamic

# Статическая (все библиотеки внутри)
gcc example.o -o example_static -static

# Частично статическая
gcc example.o -o example_partial -static-libgcc -static-libstdc++
		
```
