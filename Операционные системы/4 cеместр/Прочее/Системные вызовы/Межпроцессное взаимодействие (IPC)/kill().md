
### ` — отправка сигнала процессу**

```

#include <signal.h>
int kill(pid_t pid, int sig);
```
**Параметры pid:**

- `>0` — конкретному процессу
    
- `0` — всем процессам в группе отправителя
    
- `-1` — всем процессам (только root)
    
- `< -1` — группе процессов
    

**Пример:**

c
```
kill(1234, SIGTERM);  // Вежливое завершение
kill(1234, SIGKILL);  // Безусловное убийство
kill(getpid(), SIGSTOP);  // Остановить себя
```
