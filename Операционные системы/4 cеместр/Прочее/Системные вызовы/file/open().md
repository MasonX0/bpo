```
#include <fcntl.h>
#include <unistd.h>

int open(const char *pathname, int flags);
int open(const char *pathname, int flags, mode_t mode);
```
- **`pathname`** — путь к файлу (`"file.txt"`, `"/home/user/data"`)
    
- **`flags`** — флаги открытия (битовая маска из констант)
    
- **`mode`** — права доступа для нового файла (используется с `O_CREAT`)

```
// Тип доступа (обязательно указать ОДИН из этих трех):
O_RDONLY    // Только чтение
O_WRONLY    // Только запись  
O_RDWR      // Чтение и запись

// Опциональные флаги (можно комбинировать через |):
O_CREAT     // Создать файл, если не существует
O_TRUNC     // Обрезать файл до нулевой длины при открытии
O_APPEND    // Все записи добавляются в конец файла
O_EXCL      // С O_CREAT: выдаст ошибку, если файл уже существует
O_SYNC      // Каждая запись ждет физической записи на диск (как fsync после каждого write)
O_DSYNC     // Только данные гарантируются (как fdatasync)
O_NONBLOCK  // Неблокирующий режим (для FIFO, сокетов, устройств)
O_CLOEXEC   // Закрыть дескриптор при exec() (безопасность)
```




### Третий параметр `mode` в `open()`

Когда вы создаёте **новый** файл с флагом `O_CREAT`, нужно указать права доступа в формате **восьмеричного (octal) числа**.

### Структура прав (3 группы по 3 бита):

text

Владелец  Группа    Остальные
rwx       rwx       rwx

Каждая группа:

- **r** (4) - чтение (read)
    
- **w** (2) - запись (write)
    
- **x** (1) - выполнение (execute)
    

### Примеры:

c

// 0644 в двоичном виде:
0644 = 0 110 100 100
       ↑  ↑   ↑   ↑
       |  |   |   |
       |  |   |   └── другие: r-- (100 = 4 = только чтение)
       |  |   └────── группа: r-- (100 = 4 = только чтение)
       |  └────────── владелец: rw- (110 = 4+2 = чтение+запись)
       └───────────── специальные биты (setuid, setgid, sticky)

### Часто используемые режимы:

c

// Обычные файлы:
0644  // владелец: чтение+запись, остальные: только чтение
0600  // только владелец: чтение+запись, остальные: нет прав
0666  // все: чтение+запись (но маска umask обычно убирает execute)

// Исполняемые файлы:
0755  // владелец: rwx, остальные: r-x
0777  // все права (rwxrwxrwx), но umask ограничит

// Каталоги (нужен execute для входа):
0755  // стандартные права каталога
0700  // только владелец имеет доступ


0400 - чтение
0200 - запись
0100-исполнение

00X0 - группа владельца
0x00 - владелец 
000x - прочие
x000 - для конкретного пользователя
