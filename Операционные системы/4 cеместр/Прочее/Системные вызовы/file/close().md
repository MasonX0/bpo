```

#include <unistd.h>

int close(int fd);

```

### **Что делает:**

1. Освобождает файловый дескриптор для повторного использования
    
2. Если это последняя ссылка на файл — удаляет соответствующие записи в ядре
    
3. **НЕ гарантирует запись данных на диск!** (для этого нужен `fsync` перед `close`)
