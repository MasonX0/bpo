```
#include <unistd.h>

ssize_t write(int fd, const void *buf, size_t count);

```

### **Параметры:**

- **`fd`** — файловый дескриптор
    
- **`buf`** — указатель на данные для записи
    
- **`count`** — сколько байт записать
    

### **Важное поведение:**

- Если файл открыт с `O_APPEND`, то перед записью позиция устанавливается в конец файла
    
- Если `O_SYNC` или `O_DSYNC` — ждет физической записи на диск
    
- Иначе — данные попадают в кэш ядра
