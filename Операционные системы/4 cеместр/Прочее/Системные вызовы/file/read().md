```
#include <unistd.h>

ssize_t read(int fd, void *buf, size_t count);
```

- **`fd`** — файловый дескриптор, полученный от `open()`
    
- **`buf`** — указатель на буфер в памяти, куда читать данные
    
- **`count`** — сколько байт попытаться прочитать

### **Что происходит:**

1. Читает до `count` байт из файла, начиная с текущей позиции
    
2. Позиция в файле увеличивается на количество прочитанных байт
    
3. Данные копируются из кэша ядра в буфер пользователя
    

### **Возвращаемое значение:**

- **>0:** количество фактически прочитанных байт
    
- **0:** достигнут конец файла (EOF)
    
- **-1:** ошибка (проверять `errno`)
