```
#include <unistd.h>

off_t lseek(int fd, off_t offset, int whence);

```

изменение позиции в файле

### **Параметры:**

- **`fd`** — файловый дескриптор
    
- **`offset`** — смещение в байтах
    
- **`whence`** — точка отсчета:
    
    - `SEEK_SET` — от начала файла
        
    - `SEEK_CUR` — от текущей позиции
        
    - `SEEK_END` — от конца файла



помогает узнать размер файла, текущую позицию



```

// 1. Узнать текущую позицию
off_t pos = lseek(fd, 0, SEEK_CUR);

// 2. Переместиться на 100 байт от начала
lseek(fd, 100, SEEK_SET);

// 3. Перейти к байту -50 от конца (за 50 байт до конца)
lseek(fd, -50, SEEK_END);

// 4. Узнать размер файла
off_t size = lseek(fd, 0, SEEK_END);

```
